# 🛡️ FraudGuard AI: Credit Card Fraud Detection System

An interactive machine learning dashboard for real-time anomaly detection in credit card transactions using Unsupervised Machine Learning.

## 🚀 Live Demo
https://creditcardfrauddetection-cz4vbsdzmzyxav93eq68en.streamlit.app/

## ✨ Features
- **Single Transaction Predictor**: Input parameters directly to calculate real-time fraud risk scores.
- **Batch CSV Analysis**: Upload large transaction datasets for batch anomaly inference.
- **Visual Analytics**: Interactive PCA scatter plots and fraud rate distributions.

## 🛠️ Tech Stack
- **Machine Learning**: Isolation Forest, PCA, Scikit-Learn
- **Data Processing**: Pandas, NumPy
- **Frontend / Dashboard**: Streamlit, Seaborn, Matplotlib
